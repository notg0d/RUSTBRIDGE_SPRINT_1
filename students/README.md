Open your current `week-NN/problem_statement.md`. The actual tasks live in [weeks/](../weeks/week-01.md) and are linked, not duplicated 20 times.

Everyone practises the same skills. Build and test code first in your [own project repository](../docs/19-own-project-repo.md), then copy the working weekly files into `students/<your id>/week-NN/` here and open a pull request. Different students own bounded contributions to the single product in [shared/](../shared/README.md), with rotating implementation, test and review responsibilities. Use the [responsibility guide](../docs/06-team-roles.md); no fixed pair or absent student is a prerequisite for your practice.

Each workspace now has twenty weekly pointers. Complete the common problem-solving block along with every core task. Week 19 adds a bounded extension; it does not create a different syllabus or remove required shared contribution/review evidence.
