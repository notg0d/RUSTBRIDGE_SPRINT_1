# Learning resources and learning map

## 1. What We Are Doing

This guide gives you ONE main learning path for each week: what to read, what to watch and what to practise. Other links are marked optional. You learn alone in the Discord group, so use this map every week before you start the tasks.

## 2. Why We Are Doing It

This course uses many technologies at once: TypeScript, JavaScript, Node.js, HTTP APIs, PostgreSQL, security and React. One fixed path per topic stops you from searching alone and getting lost.

## 3. What to Learn First (Prerequisites)

- Finish the [setup guide for Mac and Windows](02-setup-guide-mac-windows.md) Step 1 to Step 3.
- Know how to open a terminal and run a command from the repository root.
- Read this file once. Then open your week file in `weeks/`.

## 5. Step-by-Step Guide

### How to use one week

1. Open your week file in `weeks/`.
2. Read section 3 and the table in section 4 of that file.
3. Read the page for your first task. Stop after the part the task names. Do not read a whole site.
4. Watch the named part of the video. Use the chapter list on the video page to jump to the start time.
5. Type the examples yourself in the TypeScript Playground (https://www.typescriptlang.org/play/) or in a file in your folder.
6. Do the task. Then run its proof.
7. If you are stuck for more than 30 minutes, ask in Discord. Post the command, the exact error text, your operating system and what you tried.

### Use AI help safely

An assistant can explain an error or suggest a small experiment. Check its answer against documentation and tests, keep secrets out of prompts and be able to explain your result. Do not submit unexplained generated code or fabricated evidence.

### Explain-back and no-AI checkpoints

Weeks 14 and 20 contain a 30-minute no-AI repair with documentation allowed. A reviewer selects a small reversible defect in the learner's own disposable exercise or code, witnesses an assertion and repair, and asks for an explanation. The time box is a checkpoint, not automatic failure: record an incomplete attempt honestly and schedule a focused retry. Public evidence records commands and technical observations, never private grades or rankings.
